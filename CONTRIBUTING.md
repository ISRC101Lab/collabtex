# Contributing

Thanks for helping CollabTeX. This project is optimized for a simple, stable paper‑writing workflow.

## Setup

```bash
npm install
npm run build
node server/index.js
```

## Development rules

- Keep changes small and focused.
- Avoid adding non‑essential UI elements.
- Prefer clarity over cleverness.
- Run `npm run build` before opening a PR.

## Pull requests

Please include:
- A short summary of the change
- What you tested and how
- Screenshots if UI changes are involved

## Code style

- Keep code plain and readable
- Avoid large refactors unless required
