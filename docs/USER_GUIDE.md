# 用户手册（CollabTeX）

本手册面向“写论文”场景，突出最短闭环：**编辑 → 编译 → PDF 预览**。

## 1. 访问与项目

- 打开 `http://<服务器IP>:4090`（或你的 `WEB_PORT`）
- 系统会**自动以 admin 身份进入**（无需登录/退出）
- 如需切换用户：点击左侧栏顶部的用户名，输入目标用户的用户名和密码
- 在项目列表中可新建项目，或导入 Zip

## 2. 基本编辑

- 在左侧文件树点击 `.tex` 文件开始编辑
- 编辑器支持 Tab、自动缩进、简单补全（含图片路径）

快捷键（默认）：
- 编译：`Ctrl/Cmd + S`
- 快速打开文件：`Ctrl/Cmd + P`
- 全项目搜索：`Ctrl/Cmd + Shift + F`
- 跳转行号：`Ctrl/Cmd + G`

## 3. 编译与 PDF 预览

- 点击右上角 **“编译”**
- 编译成功后，PDF 预览自动刷新
- “日志”页可查看编译输出与诊断摘要

## 4. SyncTeX（源码 ↔ PDF）

- 源码 → PDF：在编辑器中定位到某一行，点击工具栏 **“同步 PDF”**
- PDF → 源码：在 PDF 预览中点击内容，会自动打开对应源文件并定位行号

> 注意：SyncTeX 只对“真正参与编译的内容”有效，导言区或未被包含的行可能无法定位。

## 5. 文件管理

- 新建文件：`+ 新文件`
- 上传：`上传`
- 导出：`导出 Zip`
- 重命名/删除/移动：点击 `管理`

## 6. AI 一键修复（可选）

- 如果服务器配置了 `OPENAI_API_KEY`，编译失败时可在“日志”页点击 **“一键修复”**
- 系统会尝试修改 `.tex` 文件并重新编译

## 7. 常见问题

- **编译成功但 PDF 不更新**：确认主文件设置正确；再点击一次“编译”
- **同步失败**：确保已编译成功，且光标位于正文内容
- **PDF 点击不跳转**：确保当前 PDF 是最新编译结果
