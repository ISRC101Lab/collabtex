# CollabTeX 视频脚本（3–5 分钟）

> 目标：录一段最短闭环演示，突出“编辑 → 编译 → PDF”体验。

## 00:00 - 00:20 片头

- 标题：CollabTeX – 写论文的最短闭环
- 旁白："这是一个自托管的协作 LaTeX 编辑器，专注论文写作。"

## 00:20 - 01:00 登录与项目

- 打开浏览器 → 登录
- 展示项目列表
- 新建或打开一个项目

## 01:00 - 02:00 编辑与编译

- 打开 `main.tex`
- 修改一行（例如新增一段文字）
- 点击“编译”或使用 `Ctrl/Cmd + S`
- 解释日志与成功状态

## 02:00 - 03:00 PDF 预览与同步

- PDF 预览刷新
- 在编辑器中点击“同步 PDF” → PDF 跳转
- 在 PDF 里点击正文 → 自动回到源码行

## 03:00 - 04:00 文件管理

- 展示新建/上传/重命名/删除
- 说明适合论文写作的项目组织方式

## 04:00 - 04:40 AI 一键修复（可选）

- 故意制造一个小错误
- 点击“一键修复”
- 说明需要服务器配置 API Key

## 04:40 - 05:00 结尾

- 总结：协作、编译、预览、同步
- 标语："让写论文只剩下写作本身"

---

## 录制建议

- 录屏工具：OBS / Screenity
- 分辨率：1920x1080
- 字体：系统默认或轻量无衬线
- 录制时尽量保持 UI 简洁，隐藏无关窗口
